# 팀 할 일 보드 — 개발 계획 (MVP)

## 1. 목표
팀의 할 일을 담당자 · 기한과 함께 세 칸 보드에서 보고, 기한이 지난 일을 바로 알아본다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 세 칸 보드 · 담당자별 보기 | 로그인 |
| 할 일 추가 · 상태 변경 · 삭제 | 팀원 간 공유 (서버 저장) |
| 기한 지남 표시 | 슬랙 알림 · 댓글 · 첨부 |

## 3. 기능 명세
- F1 보드: 할 일 · 진행 중 · 완료 세 칸 · 칸 제목 옆에 개수
- F2 담당자별 보기: 위쪽 선택 상자 · 「전체」 또는 팀원 한 명
- F3 할 일 추가: 「+ 할 일」 → 추가 창 (할 일 · 담당자 · 기한) · 할 일이 비면 저장하지 않음
- F4 기한 지남 표시: 기한이 오늘보다 앞이고 완료가 아니면 빨간 테두리 · 「기한 지남」 · 칸 맨 위
- F5 상태 변경 · 삭제: 카드 클릭 → 상세 → 「다음 단계」 · 「이전 단계」 · 「삭제」

## 4. 화면별 요소
- 보드: 상단 제목 · 담당자 선택 · 「+ 할 일」 / 칸 세 개 / 카드(할 일 · 담당자 · 기한)
- 추가 창: 입력 3개 · 저장 · 닫기 · 오류 문구 자리

## 5. 데이터 항목
| 항목 | 예 |
|---|---|
| 할 일 | 주간 보고서 작성 |
| 담당자 | 김하늘 |
| 기한 | 2026-11-27 |
| 상태 | 할 일 · 진행 중 · 완료 |

저장: 브라우저 localStorage (MVP)

## 6. 완료 기준
- [ ] 첫 화면에 세 칸 보드가 보인다
- [ ] 「주간 보고서 작성 · 김하늘 · 11/27」 추가 후 새로고침해도 남아 있다
- [ ] 기한이 어제인 할 일은 빨간 테두리 · 「기한 지남」으로 칸 맨 위에 보인다
- [ ] 「다음 단계」를 누르면 진행 중 → 완료로 옮겨지고, 완료되면 기한 지남 표시가 사라진다
- [ ] 모바일 폭(390px)에서도 가로 스크롤 없이 보인다

## 7. 태스크
| 태스크 | 기능 | 끝나면 보이는 것 |
|---|---|---|
| T1 보드 화면 | F1 | 세 칸 · 칸마다 개수 |
| T2 담당자별 보기 | F2 | 「전체」 · 팀원 한 명 |
| T3 추가 창 · 저장 | F3 | 「+ 할 일」 → 할 일 · 담당자 · 기한 |
| T4 기한 지남 표시 | F4 | 빨간 테두리 · 칸 맨 위 |
| T5 상세 · 상태 변경 · 삭제 | F5 | 「다음 단계」 · 삭제 |
| T6 완료 기준 점검 | 6 | 모바일 폭 · 새로고침 뒤 유지 |

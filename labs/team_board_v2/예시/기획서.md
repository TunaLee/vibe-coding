# 팀 할 일 보드 — 기획서 v2

## 배경
- 1부 팀 할 일 보드를 팀원 8명이 함께 쓰기 시작했다.
- 할 일은 각자 브라우저(localStorage)에만 저장된다.

## 문제점
- 내 노트북에서 추가한 할 일이 팀원 휴대폰 보드에 보이지 않는다.
- 담당자 칸에 아무 이름이나 고를 수 있고, 남의 할 일도 상태를 바꾸거나 지울 수 있다.
- 기한을 공휴일로 잡아 두고 연휴가 끝난 뒤에야 알아챈다.

## 목표 이용자
- 우리 팀원 8명 · 회사 이메일로 로그인 · PC 브라우저와 휴대폰

## 서비스 컨셉
- 모두가 같은 보드를 보는 팀 할 일 보드
- 할 일 추가는 로그인한 사람만, 상태 변경 · 삭제는 담당자 본인만
- 기한으로 공휴일을 고르면 「공휴일 · 이름」을 보여 주고 저장하지 않는다

## 화면 구성
1. 로그인 화면 — 이메일 · 비밀번호
2. 보드 화면 — 1부와 같음 + 내 할 일 강조
3. 추가 창 — 할 일 · 담당자 · 기한 (공휴일 경고)
4. 할 일 상세 — 내가 담당이면 상태 변경 · 삭제 버튼

## 이번에 하지 않을 것
- 슬랙 알림 · 댓글 · 첨부 · 관리자 화면

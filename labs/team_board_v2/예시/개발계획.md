# 팀 할 일 보드 — 개발 계획 v2

## 1. 목표
팀원 모두가 같은 보드를 보고, 로그인한 사람만 할 일을 추가하며, 상태 변경 · 삭제는 담당자 본인만 한다. 공휴일은 기한으로 받지 않는다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 이메일 로그인 · 로그아웃 | 슬랙 알림 |
| 공유 보드 (DB 저장) | 댓글 · 첨부 |
| 할 일 추가 · 내 할 일 상태 변경 · 삭제 | 관리자 화면 |
| 기한 공휴일 경고 · 저장 차단 | 팀원 추가 화면 |

## 3. 기능 명세
- F1 로그인: 이메일 · 비밀번호 · 로그인 전에는 보드만 보기
- F2 공유 보드: 할 일 · 진행 중 · 완료 세 칸 · 모든 팀원이 같은 내용 · 기한 지남 표시는 1부와 같음
- F3 할 일 추가: 「+ 할 일」 → 할 일 · 담당자 · 기한 · 만든 사람은 로그인 계정 · 기한은 비울 수 있음 → 카드에 「기한 미정」
- F4 기한 공휴일 차단: 기한이 공휴일이면 「공휴일 · 이름」 표시 · 저장하지 않음
- F5 내 할 일 상태 변경 · 삭제: 내가 담당인 할 일에만 버튼
- F6 내 할 일 강조: 내가 담당인 카드는 파란 테두리

## 4. 화면별 요소
- 로그인 화면: 이메일 · 비밀번호 · 로그인 버튼 · 오류 문구 자리
- 보드: 담당자 선택 · 「+ 할 일」(로그인 후) / 세 칸 / 카드(할 일 · 담당자 · 기한) / 내 할 일은 파란 테두리
- 추가 창: 할 일 · 담당자 · 기한 · 저장 · 닫기 · 오류 문구 자리

## 5. 데이터 구조
| 표 | 열 | 예 |
|---|---|---|
| members | id · name · email | (로그인 계정) · 김하늘 · haneul@company.com |
| tasks | id · title · owner_id · due · status · created_by · created_at | 7 · 주간 보고서 작성 · (김하늘) · 2026-12-04 · 할 일 · (로그인 계정) · 자동 |

- tasks.owner_id → members.id · tasks.created_by → 로그인 계정 · due 는 비울 수 있음 (3부 회의록 에이전트가 「기한 미정」으로 올림)
- 저장 위치: Supabase (모든 팀원이 같은 DB)

## 6. 연동 대상
| 대상 | 쓰는 곳 | 키 보관 |
|---|---|---|
| Supabase DB · 로그인 | 할 일 저장 · 조회 · 로그인 | publishable 키 · 브라우저 가능 (RLS 로 보호) |
| 공공데이터포털 · 한국천문연구원 특일 정보 | 공휴일 조회 | 인증키 · .env 의 HOLIDAY_API_KEY · 서버 함수 api/holidays.js 에서만 |
| Supabase MCP (개발 중) | Claude Code 가 표 만들기 · 조회 | 개발자 계정 로그인 · 앱에는 없음 |

## 7. 권한
| 누가 | 보드 보기 | 할 일 추가 | 상태 변경 · 삭제 |
|---|---|---|---|
| 로그인 전 | ○ | ✕ | ✕ |
| 로그인한 팀원 | ○ | ○ | 내가 담당인 할 일만 |

- 표마다 RLS 켜기 · secret 키는 브라우저 · 코드 · GitHub 에 두지 않음

## 8. 완료 기준
- [ ] 내 노트북에서 추가한 할 일이 팀원 휴대폰 보드에도 보인다
- [ ] 로그인 전에는 「+ 할 일」 버튼이 보이지 않는다
- [ ] 다른 사람이 담당인 할 일에는 상태 변경 · 삭제 버튼이 없다
- [ ] 기한으로 2026-12-25 를 고르면 「공휴일 · 기독탄신일」이 보이고 저장이 막힌다
- [ ] GitHub 저장소에서 서비스 키 · secret 키가 검색되지 않는다

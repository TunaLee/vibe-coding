# 회의록 정리 (실습용 가상 자료)

- 원본: `원본/` · **읽기만 한다.** 결과는 `out/` 에 파일로
- 할 일은 담당자 · 기한 · 근거(원문 한 줄)를 함께 · 기한이 없으면 「기한 미정」 · 지어내지 않는다
- 외부 전달 금지 · 개인정보(고객 명단 등)는 결과에 옮기지 않는다
- 공유(슬랙 · 메일 발송)는 사람이 한다 · 초안까지만
- 팀 할 일 보드(Supabase tasks 표) 등록은 사람이 목록을 확인한 뒤에만 · 담당자가 members 에 없으면 올리지 않고 「보류」 · 이미 같은 할 일이 있으면 건너뜀

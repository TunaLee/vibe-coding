# 미니 노션 — 기획서

## 만들 기능
페이지 목록 · 블록 · 「/」 메뉴 · 끌어 옮기기 · 저장

## 페이지 목록
- 문제점: 회의록이 메모장 · 단톡방 · 워드에 흩어져 지난주 회의록을 못 찾았다
- 이용자: 회의가 잦은 나 · 회사 PC
- 사용 장면: 회의가 끝나면 새 페이지를 만들고, 지난 회의록은 목록에서 바로 연다
- 화면: 왼쪽에 페이지 제목 목록 · 맨 아래 「+ 새 페이지」
- 확인 문장: 「+ 새 페이지」를 누르면 목록에 「제목 없음」이 생긴다

## 블록
- 문제점: 회의록 안에서 할 일이 글 사이에 묻힌다
- 이용자: 회의록과 할 일을 같이 적는 나
- 사용 장면: 참석자 · 결정 사항은 글로, 할 일은 체크 상자로 적는다
- 화면: 줄마다 제목 · 글 · 체크 상자 · 구분선 중 하나
- 확인 문장: 체크 상자를 누르면 체크 표시가 생긴다

## 「/」 메뉴
- 문제점: 줄 종류를 바꾸려면 마우스로 버튼을 찾아야 해서 번거롭다
- 이용자: 키보드로 빠르게 받아 적는 나
- 사용 장면: 회의 중 할 일이 나오면 빈 줄에 / → 체크 상자
- 화면: 빈 줄 바로 아래 작은 메뉴 · 네 가지 종류
- 확인 문장: 빈 줄에 / → 「체크 상자」를 고르면 그 줄이 체크 상자가 된다

## 끌어 옮기기
- 문제점: 급한 할 일이 아래에 묻혀 있다
- 이용자: 할 일 순서를 자주 바꾸는 나
- 사용 장면: 급한 할 일을 맨 위로 끌어 올린다
- 화면: 줄 왼쪽에 손잡이 · 마우스를 올리면 보임
- 확인 문장: 할 일을 끌어 맨 위에 놓으면 순서가 바뀐다

## 저장
- 문제점: 창을 닫으면 쓴 내용이 날아갈까 걱정된다
- 이용자: 같은 PC 에서 다시 여는 나
- 사용 장면: 금요일에 같은 페이지를 다시 열어 끝낸 할 일을 체크한다
- 화면: 저장 버튼 없이 쓰는 대로 저장
- 확인 문장: 새로고침해도 쓴 내용이 그대로 있다

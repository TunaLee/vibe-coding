# 미니 노션 — 기획서

## 문제점
- 메모가 여러 앱 · 파일에 흩어져 있어 찾기 어렵다

## 이용자
- 나 혼자 · 회사 PC 브라우저

## 기능
- 페이지 목록 · 블록 편집 · 「/」 메뉴 · 끌어 옮기기 · 저장

## 화면
- 메인 · 왼쪽 페이지 목록 + 오른쪽 편집
- 빈 상태 · 페이지가 없을 때 첫 페이지 만들기 안내

## 확인 문장
- 「+ 새 페이지」를 누르면 목록에 「제목 없음」이 생긴다
- 빈 줄에 「/」 → 「체크 상자」를 고르면 그 줄이 체크 상자가 된다
- 할 일을 끌어 맨 위에 놓으면 순서가 바뀐다
- 새로고침해도 쓴 내용이 그대로 있다

# 미니 노션 — 기획서

## 문제점
- 회의록이 메모장 · 단톡방 「나와의 채팅」 · 워드 파일에 흩어져 있다.
- 지난주 회의록이 어느 파일에 있는지 몰라 다시 물어봤다.

## 이용자
- 회의가 일주일에 서너 번인 직장인 나 한 명 · 회사 PC 브라우저

## 사용 장면
1. 월요일 회의가 끝나면 「11/23 주간 회의」 페이지를 새로 만든다.
2. 참석자 · 결정 사항은 글로, 할 일은 체크 상자로 적는다.
3. 급한 할 일은 끌어서 맨 위로 올린다.
4. 금요일에 같은 페이지를 열어 끝낸 할 일을 체크한다.

## 예시 데이터
```
11/23 주간 회의
참석 · 김하늘 · 이준호 · 박서연 · 최민재
결정 사항 · 설문 결과는 다음 회의에서 공유
[ ] 보고서 초안 · 하늘
[ ] 설문 정리 · 준호
---
```

## 화면 스케치
- 왼쪽: 페이지 목록 · 맨 아래 「+ 새 페이지」
- 오른쪽: 큰 제목 → 줄마다 블록
- 빈 줄에서 「/」 → 블록 종류 메뉴 (노션처럼)

## 확인 문장
- 「+ 새 페이지」를 누르면 목록에 「제목 없음」이 생긴다
- 빈 줄에 「/」 → 「체크 상자」를 고르면 그 줄이 체크 상자가 된다
- 할 일을 끌어 맨 위에 놓으면 순서가 바뀐다
- 새로고침해도 쓴 내용이 그대로 있다

# 미니 노션 — 개발 계획 (MVP)

## 1. 목표
흩어진 회의록 · 메모를 페이지 하나에 블록으로 쓰고, 할 일은 체크 상자로 바로 체크한다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 페이지 목록 · 새 페이지 · 삭제 | 공유 · 공동 편집 · 로그인 |
| 블록 편집 · 「/」 메뉴 | 이미지 업로드 |
| 블록 끌어 옮기기 · 브라우저 저장 | 데이터베이스 표 · 수식 |

## 3. 기능 명세
- F1 페이지 목록: 왼쪽 목록 · 「+ 새 페이지」 · 클릭하면 그 페이지 열기 · 「페이지 삭제」 (마지막 한 장은 지우지 않음)
- F2 블록 편집: 제목 · 글 · 체크 상자 · 구분선 · 엔터 → 아래에 새 블록 · 빈 블록에서 지우기 → 블록 삭제
- F3 「/」 메뉴: 빈 블록에 「/」 → 메뉴 · 화살표 · 엔터로 블록 종류 고르기
- F4 블록 끌어 옮기기: 블록 왼쪽 「⋮⋮」 손잡이를 끌어 순서 바꾸기
- F5 저장: 입력할 때마다 저장 · 새로고침해도 마지막에 본 페이지 그대로

## 4. 화면별 요소
- 페이지 목록: 앱 이름 · 페이지 제목 줄 · 「+ 새 페이지」
- 편집 화면: 「/」 안내 · 「페이지 삭제」 / 큰 제목 / 블록 줄(손잡이 · 내용)

## 5. 데이터 항목
| 항목 | 예 |
|---|---|
| 페이지 제목 | 주간 회의록 |
| 블록 종류 | 제목 · 글 · 체크 상자 · 구분선 |
| 블록 내용 | 보고서 초안 |
| 체크 여부 | 완료 · 미완료 |

저장: 브라우저 localStorage (MVP)

## 6. 완료 기준
- [ ] 첫 화면에 페이지 목록과 「시작하기」 페이지가 보인다
- [ ] 「주간 회의록」 페이지에 체크 상자 「보고서 초안」을 추가하고 새로고침해도 남아 있다
- [ ] 빈 블록에 「/」 → 「체크 상자」를 고르면 그 블록이 체크 상자로 바뀐다
- [ ] 세 번째 블록을 맨 위로 끌어 옮기면 순서가 바뀌고 새로고침 뒤에도 유지된다
- [ ] 모바일 폭(390px)에서도 가로 스크롤 없이 보인다

## 7. 태스크
| 태스크 | 기능 | 끝나면 보이는 것 |

| T1 화면 뼈대 · 페이지 목록 | F1 | 왼쪽 목록 · 새 페이지 · 삭제 |

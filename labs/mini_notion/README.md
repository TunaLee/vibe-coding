# 미니 노션 — 바이브코딩 1부 공통 예제

노션의 핵심 기능 하나(블록으로 쓰는 페이지)만 떼어 와 작게 만든다.
1부 여덟 단원이 이 예제 하나로 이어진다. 수강생은 같은 순서로 **자기 아이디어**를 만든다.

| 단원 | 이 폴더에서 쓰는 것 | 만드는 것 |
|---|---|---|
| 1-3 기획서 | `예시/기획서.md` · `labs/persona/기획자.md` | 내 `기획서.md` |
| 1-4 개발 계획 | `예시/개발계획.md` · `labs/persona/개발자.md` | 내 `개발계획.md` |
| 1-5 Git | — | 첫 커밋 |
| 1-6 개발 | `예시/app/` (완성본 · 막히면 비교용) | 내 앱 |
| 1-7 배포 | — | Vercel 주소 |
| 1-8 회고 | — | 아쉬운 점 → 2부 |

`예시/app/index.html` 을 브라우저로 열면 바로 동작한다. 페이지는 이 브라우저(localStorage)에만 저장된다.

# 미니 노션 — 개발 계획 v2

## 1. 목표
팀원 모두가 같은 페이지 목록을 보고, 로그인한 사람만 페이지를 만들며, 수정 · 삭제는 작성자 본인만 한다. 공휴일은 날짜로 받지 않는다. Claude · ChatGPT 에서 페이지를 만들고 찾을 수 있다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 이메일 로그인 · 로그아웃 | 슬랙 알림 |
| 공유 페이지 목록 (DB 저장) | 댓글 · 첨부 |
| 새 페이지 · 내 페이지 수정 · 삭제 | 관리자 화면 |
| 날짜 공휴일 경고 · 저장 차단 | 팀원 추가 화면 |
| MCP 서버 · 페이지 만들기 · 찾기 | 페이지 삭제 도구 |

## 3. 기능 명세
- F1 로그인: 이메일 · 비밀번호 · 로그인 전에는 목록 보기만
- F2 공유 페이지 목록: 모든 팀원이 같은 목록 · 날짜 · 상태(초안 · 작성 중 · 완료) 표시
- F3 새 페이지: 「+ 새 페이지」 → 제목 · 날짜 · 작성자는 로그인 계정 · 날짜는 비울 수 있음
- F4 날짜 공휴일 차단: 날짜가 공휴일이면 「공휴일 · 이름」 표시 · 저장하지 않음
- F5 내 페이지 수정 · 삭제: 내가 작성자인 페이지에만 버튼
- F6 내 페이지 강조: 내가 작성자인 페이지는 파란 테두리

## 4. 화면별 요소
- 로그인 화면: 이메일 · 비밀번호 · 로그인 버튼 · 오류 문구 자리
- 페이지 목록: 「+ 새 페이지」(로그인 후) / 페이지 줄(제목 · 날짜 · 상태 · 작성자) / 내 페이지는 파란 테두리
- 새 페이지 창: 제목 · 날짜 · 저장 · 닫기 · 오류 문구 자리

## 5. 데이터 구조
| 표 | 열 | 예 |
|---|---|---|
| members | id · name · email | (로그인 계정) · 김하늘 · haneul@company.com |
| pages | id · title · owner_id · date · status · content · created_at | 41 · 주간 회의록 · (김하늘) · 2026-12-04 · 작성 중 · (블록) · 자동 |

- pages.owner_id → members.id · date 는 비울 수 있음 · content 는 1부 블록 내용
- 저장 위치: Supabase (모든 팀원이 같은 DB)

## 6. 연동 대상
| 대상 | 쓰는 곳 | 키 보관 |
|---|---|---|
| Supabase DB · 로그인 | 페이지 저장 · 로그인 | .env · Vercel 환경변수 |
| 공휴일 API · 특일 정보 | 날짜 공휴일 확인 | HOLIDAY_API_KEY · 서버만 |
| Supabase MCP (개발 중) | 표 만들기 · 조회 | 개발자 로그인 |
| Google Calendar (개발 중) | 일정 → 회의록 · 읽기 | claude.ai 계정 |
| 미니 노션 MCP 서버 | Claude · ChatGPT 에서 페이지 | 로그인 (OAuth) |

- 공휴일 키는 app/api/holidays/route.ts 에서만 읽음 · 브라우저에 내려가지 않음
- MCP 서버 주소 /api/mcp · 도구 add_page · list_pages · update_page · list_by_date

## 7. 권한
| 누가 | 목록 보기 | 새 페이지 | 수정 · 삭제 |
|---|---|---|---|
| 로그인 전 | ○ | ✕ | ✕ |
| 로그인한 팀원 | ○ | ○ | 내가 작성자인 페이지만 |

- 표마다 RLS 켜기 · secret 키는 브라우저 · 코드 · GitHub 에 두지 않음

## 8. 완료 기준
- [ ] 내 노트북에서 만든 페이지가 팀원 휴대폰 목록에도 보인다
- [ ] 로그인 전에는 「+ 새 페이지」 버튼이 보이지 않는다
- [ ] 다른 사람이 작성자인 페이지에는 수정 · 삭제 버튼이 없다
- [ ] 날짜로 2026-12-25 를 고르면 「공휴일 · 기독탄신일」이 보이고 저장이 막힌다
- [ ] GitHub 저장소에서 서비스 키 · secret 키가 검색되지 않는다
- [ ] Claude 대화로 만든 페이지가 목록에 보인다

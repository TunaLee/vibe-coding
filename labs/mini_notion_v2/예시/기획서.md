# 미니 노션 — 기획서 v2

## 배경
- 1부 미니 노션을 팀원 8명이 함께 쓰기 시작했다.
- 페이지가 공유되지 않는다. 만든 사람 브라우저에서만 보인다.

## 문제점
- 내 노트북에서 만든 회의록 페이지가 팀원 휴대폰에서 보이지 않는다.
- 누구나 남의 페이지를 고치거나 지울 수 있다.
- 회의 · 마감 날짜를 공휴일로 잡아 두고 연휴가 끝난 뒤에야 알아챈다.
- 캘린더 일정마다 회의록 페이지를 손으로 만든다.

## 목표 이용자
- 우리 팀원 8명 · 회사 이메일로 로그인 · PC 브라우저와 휴대폰

## 서비스 컨셉
- 모두가 같은 페이지 목록을 보는 팀 미니 노션
- 새 페이지는 로그인한 사람만, 수정 · 삭제는 작성자 본인만
- 날짜로 공휴일을 고르면 「공휴일 · 이름」을 보여 주고 저장하지 않는다
- Claude · ChatGPT 대화로 페이지를 만들고 찾는다 (MCP 서버)

## 화면 구성
1. 로그인 화면 — 이메일 · 비밀번호
2. 페이지 목록 — 1부와 같음 + 내 페이지 강조 · 날짜 · 상태
3. 새 페이지 창 — 제목 · 날짜 (공휴일 경고)
4. 페이지 화면 — 1부 블록 편집 · 내가 작성자면 수정 · 삭제 버튼

## 이번에 하지 않을 것
- 슬랙 알림 · 댓글 · 첨부 · 관리자 화면
- 회의 녹음에서 회의록 자동 작성 (3부 회의록 정리 에이전트가 맡음)

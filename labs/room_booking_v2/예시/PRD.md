# 팀 회의실 예약 — PRD v2

## 1. 목표
팀원 모두가 같은 시간표를 보고, 로그인한 사람만 예약하며, 내 예약만 취소한다. 공휴일은 예약을 받지 않는다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 이메일 로그인 · 로그아웃 | 슬랙 알림 |
| 공유 시간표 (DB 저장) | 반복 예약 |
| 예약 추가 · 내 예약 수정 · 취소 | 관리자 화면 |
| 공휴일 표시 · 예약 차단 | 회의실 추가 화면 |

## 3. 기능 명세
- F1 로그인: 이메일 · 비밀번호 · 로그인 전에는 시간표만 보기
- F2 공유 시간표: 날짜별 회의실 3열 × 09:00~18:00 · 30분 칸 · 모든 팀원이 같은 내용
- F3 예약 추가: 빈 칸 클릭 → 회의 이름 · 시작 · 끝 · 예약자는 로그인 계정
- F4 중복 예약 차단: 같은 회의실 · 이미 예약된 시간이면 저장하지 않음
- F5 내 예약 수정 · 취소: 내 예약에만 수정 · 취소 버튼
- F6 공휴일: 공휴일 날짜는 시간표 위에 「공휴일 · 이름」 표시 · 예약 창이 열리지 않음

## 4. 화면별 요소
- 로그인 화면: 이메일 · 비밀번호 · 로그인 버튼 · 오류 문구 자리
- 시간표: 날짜 · 화살표 / 회의실 3열 / 예약 칸(회의 이름 · 예약자) / 내 예약은 주황 테두리 / 공휴일 띠
- 예약 창: 회의 이름 · 시작 · 끝 · 저장 · 닫기 · 오류 문구 자리

## 5. 데이터 구조
| 표 | 열 | 예 |
|---|---|---|
| rooms | id · name · capacity | 1 · 대회의실 · 12 |
| bookings | id · room_id · date · start_time · end_time · title · user_id · created_at | 7 · 1 · 2026-12-03 · 14:00 · 15:00 · 주간 회의 · (로그인 계정) · 자동 |

- bookings.room_id → rooms.id · bookings.user_id → 로그인 계정
- 저장 위치: Supabase (모든 팀원이 같은 DB)

## 6. 연동 대상
| 대상 | 쓰는 곳 | 키 보관 |
|---|---|---|
| Supabase DB · 로그인 | 예약 저장 · 조회 · 로그인 | publishable 키 · 브라우저 가능 (RLS 로 보호) |
| 공공데이터포털 · 한국천문연구원 특일 정보 | 공휴일 조회 | 인증키 · .env 의 HOLIDAY_API_KEY · 서버 함수 api/holidays.js 에서만 |
| Supabase MCP (개발 중) | Claude Code 가 표 만들기 · 조회 | 개발자 계정 로그인 · 앱에는 없음 |

## 7. 권한
| 누가 | 시간표 보기 | 예약 추가 | 수정 · 취소 |
|---|---|---|---|
| 로그인 전 | ○ | ✕ | ✕ |
| 로그인한 팀원 | ○ | ○ | 내 예약만 |

- 표마다 RLS 켜기 · secret 키는 브라우저 · 코드 · GitHub 에 두지 않음

## 8. 완료 기준
- [ ] 내 노트북에서 한 예약이 팀원 휴대폰 시간표에도 보인다
- [ ] 로그인 전에는 빈 칸을 눌러도 예약 창이 열리지 않는다
- [ ] 다른 사람 예약에는 취소 버튼이 없다
- [ ] 2026-12-25 시간표에 「공휴일 · 기독탄신일」이 보이고 예약이 막힌다
- [ ] GitHub 저장소에서 서비스 키 · secret 키가 검색되지 않는다
